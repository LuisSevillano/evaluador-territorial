# Promo Interna Del Observatorio

Composicion Hyperframes para un video interno de menos de 60 segundos sobre el Observatorio Territorial El Buen Vivir.

## Enfoque

- Uso: circulacion interna del grupo, principalmente ordenador y WhatsApp.
- Duracion: 42 segundos.
- Formato: 16:9, 1920x1080.
- Tono: demo sobria, no anuncio para redes.
- Mensaje: ordenar datos territoriales para discutir con una base comun.

## Guion De Voz En Off

El observatorio convierte datos dispersos en una lectura comun del territorio.

La app permite explorar municipios reales con mapa, filtros, capas y ranking.

La metodologia junta indicadores, los normaliza y los agrega en bloques comparables.

El score es comparativo dentro del ambito analizado: no una verdad absoluta, sino una forma de priorizar.

El ranking ayuda a encontrar candidatos y a cambiar rapidamente los criterios.

El inspector muestra el patron de cada municipio: fortalezas, limites y tradeoffs.

Una herramienta interna para mirar el territorio con mas criterio compartido.
