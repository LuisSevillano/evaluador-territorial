# Descripcion Del Video: Atlas Territorial El Buen Vivir

## Resumen General

- Proyecto: Atlas Territorial El Buen Vivir.
- Uso previsto: video interno para presentar el Atlas al grupo.
- Duracion actual: 65 segundos.
- Formato: 16:9, 1920x1080.
- URL principal visible: `observatorio-territorial.netlify.app`.
- URL de documentacion visible: `observatorio-territorial.netlify.app/docs/`.
- Subtitulos inferiores: eliminados temporalmente para reducir carga de lectura.

## Idea Narrativa Central

El Atlas no decide por el grupo. Ayuda a comparar lugares con una base compartida y a hacer mas explicitas las conversaciones sobre que buscamos realmente.

El video debe transmitir rigor metodologico sin sonar tecnocratico: datos para explorar mejor, no para automatizar decisiones.
